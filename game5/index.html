GAME5　推理ゲーム

会話と証言を集めて、升目（マス目）パズルで事件を解き明かす　全10章のオリジナル推理ゲーム

⚠ このゲームは ブラウザでは あそべません
GAME5は Windows パソコン向けのゲーム（Unreal Engine 5 ／ C++ で制作）です。スマホ・ブラウザ上では動きません。 完成したら、下の「ダウンロード」から Windows 用のファイルを入手して あそびます。（いまは まだ配布前です）

どんなゲーム？

🗣 会話・証言
登場人物の話を聞いて、手がかりを集めます。
🔲 升目パズル
2Dのマス目に 答えを入れて 推理します。マスをクリック、または選択肢で回答。
🧑 3Dキャラクター
会話・喜び・驚き・考えこむ表情など、場面に合わせて動きます。
📚 全10章
章ごとに事件と推理問題。クリアすると評価が出ます。やりなおしも可能。
💡 ヒント・難易度
こまったらヒント。難易度は自分で選べます。
💾 セーブ
オートセーブ1枠 ＋ 手動セーブ5枠。
