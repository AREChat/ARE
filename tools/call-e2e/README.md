# 通話の録音・録画／＋メニューの通しテスト（ブラウザ2つ）

ブラウザを2つ（別々の保存領域）ひらき、本物の WebRTC で通話をつないで、`chat-call.js / chat-call-rec.js / chat-call-plus.js` を
そのまま動かします。GAS（郵便受けと、ドライブへのアップロード口）と ドライブは、`lib.js` の中の疑似サーバーが `gas/file-storage.gs` と同じ決まりで受けます。

- 準備：`npm i --no-save terser@5.51.2 acorn`（リポジトリ直下）／ Playwright（グローバル）／ ffmpeg
- 実行：`NODE_PATH=$(npm root -g) node tools/call-e2e/t1.js`（t1〜t6。1本ずつ。`MIN=1` を付けると、本番と同じ圧縮をかけた版で動かします）
  - t1 ふつうのユーザー同士：自動で録画／止められない／ドライブへ自動で送られる／録画が本物の動画か（ffprobe・ffmpeg）
  - t2 管理者だけが止める・再開できる（相手の端末も同じになる）／管理者でない相手の指示は聞かない
  - t3 ＋メニューの15機能を ひとつずつ動かす
  - t4 失敗・再送・続きから・オフライン・タブを閉じた復旧・非対応端末・記録の画面・通話に譲る送信
  - t5 4か国語で日本語が残っていないか／管理者がかけた側のとき
  - t6 約2分の長い通話（操作しながら）＋すぐ2本目
- 外のネットには つなぎません（STUN も ごく小さな疑似サーバー）。画面のスクリーンショットは `/tmp/call-e2e/` に出ます。
