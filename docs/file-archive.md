# 30日たったファイルを Google ドライブに移す（ファイル保存フォルダ）

## 何をするしくみ？

- チャットに送られた**ファイル**（txt・pdf・docx・zip など。画像・動画・ボイスは、いまは対象外）が、送られてから **30日** たつと、自動で
  1. あなたの Google ドライブの **「ファイル保存フォルダ」**（月ごとの小さなフォルダに分かれます）に保存され、
  2. 保存できたことを確かめてから、チャット側のファイルを消し、
  3. チャットには「30日たったので、チャットからは消えました。運営の保管場所（Google ドライブ）に移しています。」というカードが残ります。
- 1時間に1回、最大5ファイルずつ動きます（1日で最大120ファイル）。
- **ドライブに保存できなかったときは、何も消しません。** 次の回にやり直します（5回続けて失敗したら、そのファイルは止めて、記録に残します）。
- ドライブでのファイル名は `20261101-1230_送った人_元の名前[メッセージ番号8文字].拡張子` の形です（日本時間）。

## 一度だけやる準備（3つ）

### 1. SQL を実行する（Supabase・本番「ARE」）

1. Supabase を開き、本番のプロジェクト「ARE」→ 左の **SQL Editor** → **New query**。
2. `sql/file_archive_v1.sql` の中身を、**全部**コピーして貼り付ける。
3. **Run**。いちばん下に、確認の結果が3つ出ます。
   - cron の行が **1 行**（`file-archive-hourly`）
   - 関数が **4 つ**（`file_archive_…`）
   - 30日たったファイルの件数（いまの数。0 でも正常です）
4. このSQLは、何回実行しても大丈夫な書き方です。

### 2. Google ドライブの「受け口」を作る（Google Apps Script）

1. <https://script.google.com> を開く → **新しいプロジェクト**。
2. 最初からあるコードを全部消して、`docs/file-archive-gas.js` の中身を、全部貼り付ける → 保存。
3. 左の ⚙ **プロジェクトの設定** → いちばん下の **スクリプト プロパティ** → **スクリプト プロパティを追加**
   - プロパティ：`ARCHIVE_TOKEN`
   - 値：**自分で作った、長いランダムな文字列**（40文字以上。英数字を適当に並べる。パスワード管理アプリで作ると楽です）
   - **この文字列は、チャットや Claude には書かないでください。** 手順3の Supabase にだけ、同じものを入れます。
4. 右上 **デプロイ** → **新しいデプロイ** → 種類の歯車 → **ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（※「全員」でも、合言葉が合わない呼び出しは全部断ります）
5. **デプロイ** → 「アクセスを承認」が出たら、自分の Google アカウントで許可（「ドライブ」と「外部サービスへの接続」が求められます。「このアプリは確認されていません」と出たら、**詳細** → **（安全ではないページ）に移動** を選びます。自分で作ったアプリなので大丈夫です）。
6. 最後に出る **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピー。
   - ブラウザでその URL を開くと「ファイル保存フォルダの受け口は動いています。」と出れば成功です。

### 3. Supabase に、2つの設定（Secrets）を入れる

1. Supabase の本番「ARE」→ **Edge Functions** → **Secrets**（または Project Settings → Edge Functions → Secrets）。
2. 2つ追加：
   - `DRIVE_ARCHIVE_URL` … 手順2でコピーした URL
   - `DRIVE_ARCHIVE_TOKEN` … 手順2で決めた、`ARCHIVE_TOKEN` と**まったく同じ**文字列
3. 終わったら、Claude に「ドライブの設定ができた」と伝えてください。Claude が、テスト用のファイルで、最初から最後まで動くか確認します（確認が済むまで、本物のファイルは動きません。30日たった本物のファイルがあれば、確認のあとに動き出します）。

## 止めたいとき

- いちばん簡単：Supabase の Secrets から `DRIVE_ARCHIVE_URL` を消す → すぐに何もしなくなります（ファイルは消えません）。
- 完全に止める：SQL Editor で `select cron.unschedule('file-archive-hourly');`

## 知っておいてほしいこと

- **プライバシー**：ここに移ったファイルは、あなたの Google ドライブに入ります。つまり、**運営者（あなた）が、ユーザーのファイルを読める**状態になります。ユーザーに説明する文（`privacy.html` など）に、「30日たったファイルは、運営の保管場所に移される」という一文を入れるかどうかは、あなたが決めてください（Claude は勝手に書き換えていません）。
- 移したあと、チャットからは**元に戻せません**（ドライブから、手でダウンロードして渡す形になります）。
- Google ドライブの無料の容量は、ふつう **15GB**（Gmail・写真と共通）です。多くなってきたら、「ファイル保存フォルダ」の古い月を整理してください。
- 同じファイルが、同じ部屋の別のメッセージ（転送など）で使われていたときは、すべて「移しました」の表示に切りかわります。
- ほかの部屋のファイルや、保存先のパスが「部屋/送った人/…」の形になっていないものは、対象外にしています（安全のため）。
- 対象は、いまは「ファイル」だけです。画像・動画・ボイスは、アルバムや写真の表示も直す必要があるため、あとで検討します。
- これは、管理者パネルの「バックアップ」（毎日の自動保存）とは別のしくみです。
