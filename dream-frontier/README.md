# ドリーム・フロンティア（Dream Frontier）

HTML・CSS・JavaScript だけで つくった、**オリジナルの 一人称 3D テーマパーク RPG**。サーバー不要・無料の GitHub Pages で 公開できます。
ARE QUEST 2 の サブストーリーとして 組み込むことも、単独で あそぶことも できます。

> **この README の「できていること」は、実際に 動かして 確認した ことだけを 書いています。**
> 確認できていないことは「未確認」と はっきり 書きます。

### Three.js について（正直な 現状）
このゲームは **Three.js を 優先**して 読みこみ、見つからない／失敗した 時は **自動で 自作 WebGL2 版に きりかえ**ます（理由は「しんだん」画面に 出ます）。

* `vendor/three/` に 公式ファイルを おく 仕組み（`tools/fetch-three.mjs`）と、Three.js 用の 描画コード（`js/backend-three.js`）は 入っています。
* ただし 制作環境が インターネットに つながらず、**公式の Three.js を 入手することも、Three.js で 実際に 描画することも できませんでした**。
  `backend-three.js` は「ニセの 部品で 配線だけ 確かめた」段階で、**本物の Three.js での 見た目・動作は 未確認**です。
* 公式ファイルを 置いたら、URL に `?diag=1` を つけて ひらき「描画エンジン」が `Three.js r160` に なっているか 確認してください。
  おかしい 時は `?engine=gl2` で いつでも WebGL2 版に もどせます。

## 自分の PC で うごかす
`file://`（ファイルを ダブルクリック）では ES Modules が ブロックされ **動きません**。ローカルサーバーを つかってください。
```
cd dream-frontier
python3 -m http.server 8000      # または  npx serve  /  VS Code の Live Server
```
ブラウザで `http://localhost:8000/` を ひらく。（`localhost` では F12 などの ガードは 自動で 解除されます）

公式 Three.js を おく（任意）：`node tools/fetch-three.mjs`（Node.js 18+ と インターネット が ひつよう）

## GitHub Pages で 公開する（無料）
いまの サイト（`https://sakai-tomohiko124.github.io/ARE/`）に **サブフォルダとして 追加**する 方法が かんたんです。

1. リポジトリ `ARE` の 中に `dream-frontier/` フォルダごと アップロード（`game2/` と **同じ 階層**）。
   - `.github` と `.nojekyll` は 隠しファイルです。**単独で 公開する時だけ** 必要（サブフォルダの 場合 `.github/workflows` は リポジトリの 直下に ないと 動きません）。
2. （おすすめ）自分の PC で `node tools/fetch-three.mjs` を 実行し、できた `vendor/three/` の 3ファイルも アップロード。
3. Settings → Pages で ブランチ（`main`）・`/ (root)` を 選ぶ（すでに 設定ずみなら そのまま）。
4. 1〜2分 まって `https://…github.io/ARE/dream-frontier/` を ひらく。
5. `game2` の 町の「ドリーム・フロンティア入口」から 入ると 自動で このゲームが ひらきます（`dream-frontier/` が 見つからない時は 内蔵の ミニパーク）。

**単独の リポジトリ**で 公開する 場合は Settings → Pages → Source を「GitHub Actions」にすると、`.github/workflows/pages.yml` が 自動で 公式 Three.js を 取得して 公開します。

### 公開後に 更新が 反映されない時
GitHub Pages の JS/CSS は ブラウザに 約10分 キャッシュされます。**Ctrl+Shift+R**（スマホは 履歴・サイトデータの 削除）で 読みこみなおしてください。

## 「ゲームが はじまらない」時の しらべかた
1. ページを ひらいて **8びょう**まつ → 自動で **しんだん画面**が でます（URLの おわりに `?diag=1` でも ひらけます）。
2. しんだん画面の **NG** の ファイルが「アップロードされていない／名前が ちがう」ものです。`vendor/three/…` と `js/backend-three.js` が NG でも **WebGL2 版で あそべます**。
3. それ以外の NG が あれば アップロードしなおして **Ctrl+Shift+R**。
4. 「WebGL2: NG」なら その ブラウザ／端末では 3D が 使えません（別の ブラウザを ためす）。
5. 画面を スクショ（または「診断をコピー」）して 見せてください。

## F12・右クリックの ガードについて
`js/boot.js` が 公開サイト上で F12・右クリック・Ctrl+Shift+I/J/C・Ctrl+U を ふさぎます。ただし これは **かんたんな ぼうし**で、ブラウザの メニューや 別の方法からは 開けます（**完全には ふせげません**）。
開発する時は URL に `?dev=1` を つける（`localhost` は 自動で 解除）。
